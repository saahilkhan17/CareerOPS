# Plan 01-01: Bootstrap skeleton

**Goal:** Runnable FastAPI skeleton with health checks, config, logging, async DB
wiring, migrations, and a green `lint test` — no Docker required for verification.

## Tasks

### 1. Root config files

<action>
Create `pyproject.toml` (project metadata, runtime deps, dev extras, pytest +
ruff + mypy config), `.env.example` (DATABASE_URL, REDIS_URL, APP_ENV,
LOG_LEVEL), `docker-compose.yml` (postgres:16 + redis:7 with healthchecks,
named volume, nothing else), `Makefile` (services/run/worker/beat/test/lint/
migrate/revision/seed targets per AGENTS.md; seed errors as unimplemented).
</action>
<read_first>
- `AGENTS.md` (commands + stack sections)
</read_first>
<acceptance_criteria>

- `make help` (or reading Makefile) lists services/run/worker/beat/test/lint/migrate/revision
</acceptance_criteria>

### 2. App core (config, logging, middleware)

<action>
Create `app/core/config.py` with `Settings(BaseSettings)` — fields app_name,
env, database_url, redis_url, log_level; `get_settings()` cached via lru_cache.
Create `app/core/logging.py` — stdlib JSON formatter including `request_id`
from a ContextVar, `configure_logging(level)` idempotent.
Create `app/core/middleware.py` — RequestIdMiddleware: reuse/propagate
`X-Request-ID` or uuid4 hex, set on request.state + response header, one JSON
access log line per request.
</action>
<read_first>
- `AGENTS.md` (config-via-env, structured logging + request ID rules)
</read_first>
<acceptance_criteria>
- `python -c "from app.core.config import get_settings"` exits 0
- Log output line parses as JSON and contains `request_id` key
- Response to any request carries `X-Request-ID` header
</acceptance_criteria>

### 3. App factory + DB wiring

<action>
Create `app/db/base.py` (SQLAlchemy DeclarativeBase subclass `Base`),
`app/db/session.py` (create_async_engine from settings, async_sessionmaker,
`get_session` async-generator dependency).
Create `app/main.py` with `create_app()` factory: middleware, GET /health
(always 200 `{"status":"ok"}`), GET /ready (`SELECT 1` → 200
`{"status":"ready"}`, failure → 503 error envelope), 404 + Exception handlers
returning `{"error": {"code","message"}}` envelope, `app = create_app()`
module-level for uvicorn.
</action>
<read_first>
- `app/core/config.py`, `app/db/session.py` (after task 2)
- `PRD.md` §6.6 PLT-1/PLT-3
</read_first>
<acceptance_criteria>
- `GET /health` returns 200 `{"status": "ok"}`
- `GET /nonexistent` returns 404 `{"error": {"code": "not_found", ...}}`
- `GET /ready` with unreachable DB returns 503 with `error` envelope
- OpenAPI schema at /openapi.json includes /health and /ready
</acceptance_criteria>
